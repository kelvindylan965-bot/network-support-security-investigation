\# Network Support, Security and Incident Investigation



\*\*Author:\*\* Kelvin Kiptoo Ngetich



\## About the Project



This project is a practical introduction to network troubleshooting and traffic analysis using Wireshark. I investigated DNS queries and responses, examined TCP traffic, and looked at QUIC packets while testing access to `example.com`.



The aim was to understand how network traffic can be examined and how packet evidence can help with basic network support and investigation.



\## Tools Used



\- \*\*Wireshark\*\* — capturing and analysing network packets

\- \*\*Windows PowerShell\*\* — running commands and organizing project files

\- \*\*nslookup\*\* — checking DNS resolution

\- \*\*Web browser\*\* — testing
